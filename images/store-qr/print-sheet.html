Print specification

  • Do not crop the white margin. The 4-module quiet zone is part of the code and is included in the 62 mm box.
  • Minimum size is 14 mm / 18 mm (App Store / Google Play) — the 62 mm layout above is well above it.
  • Distance rule: viewing distance ÷ 10 = minimum code width. For a roll-up read from 2 m, scale the code to at least 200 mm.
  • Scale from the SVG (images/store-qr/*.svg), never by upscaling a PNG. Regenerate at 2048 px if a raster is required.
  • Reproduce in solid black or #0F172A on white. Do not tint to a mid-tone brand colour or reverse it out — contrast is what makes it scan outdoors.
  • No logo overlay. Adding one requires error correction H and an overlay under ~10% of the code area; regenerate the artwork rather than placing a logo on top.
